## 議題 1 社内文書の検索をどうするか

社内の文書が、Confluence、共有ドライブ、各リポジトリの docs ディレクトリに散らばっていて、探すのに時間がかかっているという話が出た。

- 佐藤: 新しく入った人が、手順書を見つけられずに古い手順で作業してしまったことが先月 2 回あった。
- 田中: 自分も、デプロイ手順を探すときに毎回ブックマークをたどっている。
- 鈴木: ローカルで動く検索の試作を作ってみたい。まずは docs ディレクトリだけを対象にして、全文検索ができるところまで。
- 高橋: Confluence は権限の問題があるので、後回しにしたほうがいい。

結論: ローカル検索の試作を進める。対象はまず docs ディレクトリだけにする。
