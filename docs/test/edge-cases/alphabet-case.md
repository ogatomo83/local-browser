# 英字の大文字と小文字の区別

この文書は、英字の大文字と小文字を区別せずに検索できるかを確かめるためのものです。
社内の文書には、技術用語が英字のまま書かれていることがよくあります。書き方が人によって違っても、同じ語として見つかる必要があります。

## 表記の揺れの例

同じものを指していても、書く人によって表記が変わります。

- Kubernetes、kubernetes、KUBERNETES
- PostgreSQL、postgresql、Postgres
- GitHub、github、Github

どの書き方で検索しても、この文書が見つかるはずです。

## 短い略語

3 文字未満の語は、全文検索の仕組み上そのままでは見つけられないため、別の方法で探しています。

- k8s は Kubernetes の略です。k と s の間に 8 文字あることから、こう書きます。
- CI は変更のたびに自動でテストを動かす仕組みです。
- DB はデータベースの略です。

これらの語で検索しても、この文書が見つかるはずです。

## 日本語と英字が混ざった文

「Kubernetes のクラスタに PostgreSQL を載せるかどうか」のように、日本語と英字が混ざった文もよくあります。
語の区切りに空白がなくても、部分一致で見つけられることを確かめます。
