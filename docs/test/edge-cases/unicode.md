# いろいろな文字の確認

この文書は、日本語以外の文字や記号が混ざっていても、正しく読み込めて検索できるかを確かめるためのものです。

## 絵文字

リリースが終わったら 🚀 を、障害が起きたら 🔥 を、復旧したら ✅ を Slack に付ける習慣があります。
絵文字で検索しても、この文書が見つかるはずです。

## 半角カナと全角英数字

古いシステムから移した文書には、半角カナ (ﾃﾞｰﾀﾍﾞｰｽ) や全角の英数字 (ＡＢＣ１２３) が残っていることがあります。
表示が崩れないことを確かめます。

## 記号

丸数字 ①②③、ローマ数字 Ⅰ Ⅱ Ⅲ、単位 ㎏ ㎡、矢印 → ← ↑ ↓、括弧 「」『』【】 など。

## 旧字体と異体字

髙橋 と 高橋、﨑 と 崎 のように、人名には見た目の似た別の字が使われることがあります。
今の検索では一部の異体字を同じ字として扱うので、「高橋」で探しても「髙橋」が見つかります。
