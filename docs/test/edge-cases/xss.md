# 危険な書き方の確認

この文書は、Markdown の中に危険な書き方が混ざっていても、画面で何も起きないことを確かめるためのものです。
下の例はどれも、文字として表示されるか、無効なリンクになるはずです。

## スクリプトを直接書いた場合

<script>alert('スクリプトが動いた')</script>

上の行は、画面にそのまま文字として表示されるはずです。実行されてはいけません。

## 画像の読み込み失敗を使った場合

<img src=x onerror="alert('画像の仕掛けが動いた')">

これも文字として表示されるはずです。

## 危険なリンク

[押すとスクリプトが動くリンク](javascript:alert(1))

このリンクは、押しても何も起きないはずです。

## 普通のリンク

- [外部のサイト](https://example.com) は、本物のブラウザの新しいタブで開くはずです。
- [存在しない文書](./nothing.md) は、「リンク先が見つかりません」と表示されるはずです。
- [索引の対象外の場所](../../../../etc/hosts) は、「索引の対象外の場所です」と表示されるはずです。
- [同じ文書の中の見出し](#普通のリンク) は、この見出しまでスクロールするはずです。

## まとめ

社内の文書は誰でも書けるので、うっかり危険な書き方が混ざることがあります。
このツールでは、Markdown の中の HTML はすべて文字として扱い、危険なリンクは無効にしています。
HTML ファイルは、スクリプトが動かない枠の中で表示します。
