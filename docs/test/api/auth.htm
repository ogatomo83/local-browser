認証方式

API は OAuth 2.0 の Bearer トークンで認証します。トークンは認証サーバから受け取り、API を呼ぶたびにヘッダに付けます。

トークンの受け取り方

  1. 利用者をログイン画面に案内する。
  2. ログインに成功すると、指定した戻り先に一時的なコードが渡される。
  3. そのコードを認証サーバに送り、アクセストークンとリフレッシュトークンを受け取る。

トークンの付け方

Authorization: Bearer (アクセストークン)

トークンをアドレスの後ろ (クエリ文字列) に付けてはいけません。サーバのログやブラウザの履歴に残ってしまうためです。

有効期限

  • アクセストークンの有効期限は 1 時間です。
  • 期限が切れると 401 が返るので、リフレッシュトークンを使って新しいアクセストークンを受け取ってください。
  • リフレッシュトークンの有効期限は 30 日です。使うたびに新しいものに入れ替わります。

権限の範囲

トークンには、何ができるかを表す「スコープ」が付いています。必要なスコープだけを求めてください。

  • users:read 利用者の情報を読む
  • users:write 利用者の情報を書き換える
  • orders:read 注文の情報を読む
  • orders:write 注文を作る、取り消す

やってはいけないこと

  • トークンをソースコードや設定ファイルに直接書く。
  • トークンを Slack やメールで送る。
  • テスト用のトークンを本番で使う。
