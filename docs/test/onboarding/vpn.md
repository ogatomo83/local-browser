# VPN の設定

社外から社内のネットワークに入るには VPN が必要です。自宅や出張先から作業するときは、必ず VPN につないでから社内のサービスを使ってください。
この文書では macOS と Windows の設定方法と、つながらないときの対処をまとめています。

## 事前に用意するもの

- 情報システムから共有された VPN サーバの名前
- 社内アカウントのユーザー名とパスワード
- 二段階認証用のスマートフォンアプリ

サーバの名前は社外秘です。この文書には書かず、パスワード管理ツールの共有の保管庫に置いています。

## macOS の場合

1. 「システム設定」を開き、左の一覧から「VPN」を選ぶ。
2. 「VPN 構成を追加」から「IKEv2」を選ぶ。
3. 表示名に「社内 VPN」と入れる。
4. サーバアドレスとリモート ID に、共有されたサーバ名を入れる。
5. 認証方式は「ユーザー名」を選び、社内アカウントを入れる。
6. 「作成」を押し、一覧に出た「社内 VPN」をオンにする。
7. スマートフォンに届いた通知を承認する。

メニューバーに VPN の状態を出しておくと、つながっているかどうかがすぐに分かります。

## Windows の場合

1. 「設定」から「ネットワークとインターネット」、「VPN」を開く。
2. 「VPN を追加」を押す。
3. VPN の種類は「IKEv2」を選び、サーバ名を入れる。
4. サインイン情報の種類は「ユーザー名とパスワード」を選ぶ。
5. 保存したら「接続」を押し、スマートフォンの通知を承認する。

## つながらないとき

| 症状 | 考えられる原因 | 対処 |
|---|---|---|
| 認証エラーになる | パスワードの有効期限切れ | 社内ポータルからパスワードを変更する |
| 認証エラーになる | 二段階認証の通知を見逃した | もう一度接続し、30 秒以内に承認する |
| タイムアウトする | 自宅のルータが通信を止めている | ルータの設定で UDP の 500 番と 4500 番を許可する |
| つながるが社内サイトが開けない | DNS の設定が反映されていない | `scutil --dns` で社内の DNS が入っているか確かめる |
| ホテルの Wi-Fi でつながらない | 公衆回線が VPN を止めている | スマートフォンのテザリングを使う |

上の表で解決しない場合は、#it-help チャンネルに、使っている OS、エラーの文言、試したことを書いて相談してください。

## 注意事項

- VPN につないだまま、私的な動画の視聴や大きなファイルのダウンロードをしないでください。社内の回線が混みます。
- 公共の場所で作業するときは、画面をのぞかれないように気をつけてください。
- PC を紛失したときは、すぐに情報システムに連絡してください。VPN の接続権限を止めます。
