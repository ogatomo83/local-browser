# コーディング規約

チーム共通のコーディング規約です。迷ったらここを見てください。

## 命名

- 変数名は英語で、略語は避ける
- ブール値は `is_` / `has_` で始める
- API のエンドポイントはケバブケース

## エラー処理

Rust では `anyhow` を使い、ライブラリでは `thiserror` を使います。
エラーを握りつぶさないこと。ログに残すときは request_id を必ず含めます。

## テスト

- 単体テストは同じファイルの `mod tests` に書く
- 外部 API はモックする
- CI では `cargo test --all` が通ること

詳しくは [レビューの進め方](./review.md) も参照。
